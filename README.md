## About
StudyBuddy is an all-in-one application that helps students focus by integrating multiple standalone applications into a unified, minimalistic and easy-to-understand system, thereby reducing distractions. 

#### StudyBuddy Experiences:

- RAG-powered AI Chatbot
- Document Upload and previews
- Focus Timer
- Music Player
- Journal
- To-do List
- Personalization Elements

## Getting Started

Clone the GitHub Repository

```bash
git clone https://github.com/piyushvarman/student-productivity-dashboard
```

Move into the folder

```bash
cd student-productivity-dashboard
code .
```

Run the Development Server
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to use StudyBuddy.
